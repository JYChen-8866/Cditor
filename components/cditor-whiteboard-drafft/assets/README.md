# Whiteboard fonts

The UI and canvas fonts mirror `korbinjoe/excalidraw-cn` at commit
`0472657546460d5fb8ec075b8c9da4abae55c7e5`:

- UI: Assistant Regular, Medium, SemiBold and Bold.
- Canvas Latin text: Virgil.
- Canvas CJK text on macOS: the system `HanziPen SC` font, followed by
  `Cangnanshoujiti` and `KaiTi` when available.

The copied repository license is retained in `excalidraw-cn-LICENSE`.
